# Class and widget index

[Plan and status rules](../WXWIDGETS-COVERAGE.md). All concrete widgets, abstract
bases, helper classes and structs declared in the pinned interface headers are
listed together so less familiar widgets are not omitted. `[x]` means full class
coverage including inherited APIs; `[~]` means the annotated partial support.
Statuses and supported Lisp names are preserved in [status.json](status.json).
Forward declarations are represented in the per-header declaration inventories.
